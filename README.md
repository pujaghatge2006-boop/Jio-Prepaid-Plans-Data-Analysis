** Jio Prepaid Plans – Data Analysis & Power BI Dashboard **

 📊 Project Overview

This project analyzes Jio prepaid plans to understand pricing, plan validity, data benefits, and the overall value offered across different prepaid plans.

The project involved data cleaning, creating calculated metrics, performing exploratory data analysis, and building an interactive Power BI dashboard to present the findings visually.

🎯 Project Objective

The main objectives of this project are to:

* Analyze prepaid plan pricing and validity
* Compare the cost of plans across different durations
* Analyze data benefits offered by different plans
* Calculate and compare price per day
* Calculate and compare price per GB
* Identify patterns between plan price, validity, and data benefits
* Present the analysis through an interactive Power BI dashboard

 🗂️ Dataset

The dataset contains information about Jio prepaid plans, including:

* Plan validity/duration
* Plan price
* Data offered
* Daily data allowance
* Calls
* SMS
* 5G benefits
* OTT benefits
* Other calculated plan metrics

The dataset was prepared and analyzed before creating the final dashboard.

 🧹 Data Preparation

The data was cleaned and transformed before analysis.

The preparation process included:

* Checking the dataset structure
* Handling missing or inconsistent values
* Cleaning data fields
* Creating calculated columns
* Categorizing plan validity
* Calculating price per day
* Calculating annualized cost
* Calculating total data
* Calculating price per GB
* Preparing the dataset for Power BI visualization

📈 Key KPIs

The Power BI dashboard includes key metrics such as:

* Minimum Plan Price
* Maximum Plan Price
* Average Plan Price
* Average Price per Day
* Total Data Offered
* Average Price per GB
* Plan Validity Analysis

These KPIs provide a quick overview of the pricing and value characteristics of the available plans.

 📊 Power BI Dashboard

The final Power BI dashboard brings together KPIs and visualizations to compare:

* Plan pricing
* Plan validity
* Price per day
* Data benefits
* Price per GB
* Pricing versus validity
* Pricing versus data offerings


🔍 Key Insights

The analysis helps identify differences in pricing and value across prepaid plans.

Some of the observations include:

* Plan prices vary considerably across different validity periods.
* Longer-validity plans generally have a higher upfront price.
* Price per day provides a useful way to compare plans with different validity periods.
* Price per GB helps compare the relative cost of data across plans.
* Plans can be compared using multiple factors rather than price alone, such as validity and data benefits.
* The dashboard provides a visual way to identify pricing and data patterns across the available plans.
